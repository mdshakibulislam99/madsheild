Capabilities

Everything you need to vet a file

From Office documents to Windows executables — one analyzer, consistent reports, full traceability.

Static rule engine

Detects encoded PowerShell, download-and-execute chains, shadow-copy deletion, Office macros, PDF structural markers and suspicious Windows API imports.

AI model inference

Optionally plug in your existing model. Rule findings and model predictions are reported separately, with explicit coverage and status — never blended together.

Batch & folder scans

Analyze up to 100 files (100 MiB) per batch. Safe relative folder paths are preserved in reports, and duplicate content reuses cached results for five minutes.

Evidence-backed reports

Every report includes SHA-256, a clear verdict, each finding with its exact location and quoted content, timings, and honest limitations of the analysis.

Broad format coverage

.txt, .log, .csv, .json, .md, .doc, .docx, .pdf, .zip, .exe and .dll — with size, nesting, page and member limits that keep hostile files from exhausting the server.

Local & private

Runs entirely on your own machine or network. Files are quarantined for analysis only — nothing is uploaded to a third party, and nothing is executed.

Workflow

From upload to verdict in three steps

No configuration, no agents, no file execution — just drop a file and read the evidence.

Upload

Drop a single file or a whole folder. Names, extensions, count and actual sizes are validated before anything is analyzed.

Analyze

Content is extracted safely — text, DOCX paragraphs, PDF pages, ZIP members, legacy DOC strings, or PE metadata — then checked against the rule engine and your model.

Report

Get a saved, shareable report with a verdict, located findings, hashes and timings. Identical content is served from cache for speed.
